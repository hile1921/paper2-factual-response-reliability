# Current private repository scope

Included: all 319,410 retained longitudinal model responses (117 completed task files), frozen machine-assisted audit records and cached reference snapshots; matched-panel candidate scores, raw text and labels; both contextual rounds (414,400 outputs); forward-model inputs and evidence/excerpt snapshots; the Appendix A control's evaluations and completed training-cell logs; original scripts, portable CPU adapters, expected result tables, plotting data/code, and integrity reports.

Verified now: five analysis chains and 55 table comparisons; exact raw-join and offline evidence-gate replay for the longitudinal panel. Text-only legacy encoding warnings in the single-case control are explicitly retained.

Not included: model weights, complete training corpora, large retrieval indexes, credentials, full manuscript, named author declarations. Missing original contextual runtime-wrapper logs cannot be recovered from summaries. Some historical secondary diagnostics are retained but not rerun by the main entry point; their filenames are listed in each report. A full new human or external-source adjudication has not been performed.

No public licence has been selected and no public release is authorised. Original code, generated outputs, cached reference data and training excerpts have different provenance; inspect their respective third-party rights and attribution before any public release. The snapshots support private reproducibility preparation and are not an assertion of unrestricted redistribution rights. See REPRODUCIBILITY.md and ARCHIVE_FILE_PROVENANCE.json.
