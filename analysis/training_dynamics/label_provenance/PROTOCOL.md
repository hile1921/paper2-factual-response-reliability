# P1 独立确证冻结协议

实验单位为面板中的事实 UID（subject ID、property ID、object ID）。按面板原顺序选取未进入旧 P1 的 159 条，保留同一事实的全部预期单元。任何已存在且模型、检查点、提示和解码协议一致的单元直接复用。不同协议的旧诊断不作为本实验单元。所有主体及输出均保留，缺少事实证据按规则弃判。旧 P1 的 114 个 Wikidata 主体与本轮主体无重叠。

生成使用服务器上的原始脚本，LMEnt-1B-6E，步数 10,000、340,000、658,032，原有两模板及批大小 64。greedy 加四个原种子，temperature 0.8、top-p 0.95、最多 12 个新 token，左填充、bf16、SDPA，提示无尾空格。此次批次由新事实组成，随机流仍为原批次级播种。不同面板不会逐记录共享相同随机数。

使用原 P1 的提取函数和候选判定，并保留提取状态。事实层要求正面证据，这是预先固定的保守证据门槛。旧 P1 的 94 条机器判错已知存在链接问题，因此旧标签单独保留，同一门槛重评旧 P1 的全部 3,420 条。主要比较以同一证据门槛的标签为准，同时报告历史原始效应。对已知风险的规则在新输出读取前固定，详见核验代码。取证只发固定面板的公共 QID 和公开数据库下载请求，输出文本及其衍生搜索词留在本地。数据库缺失、别名冲突、粒度不明、历史歧义或真伪冲突证据不足均记 unverified。

首要指标为全部 159 条的末期减早期 `correct_verified / 全部尝试`。主体聚类配对 bootstrap 5,000 次，种子 20261110，双侧百分位 95% 区间。确认成功要求首要差为正且区间下界大于 0。按 Capital 和 Country 分别报告，并标明哪一关系支撑总体差。错误率方向及大小是独立结果，无升降硬门槛。次要分析为每阶段候选断言率、机器可核实有效断言率（正确加错误除以全部尝试）、覆盖率（正确加错误除以候选断言）、正确率、错误率、候选内未核验量，以及三个阶段对比。以主体重采样保留所有模板和解码。模板、解码及交叉分层为描述性，未校正多重性。未核验敏感性与主体抽样区间分开，报告各阶段独立设定未核验真假时的错误率差范围，条件是其他标签正确。

正确率复现只支持相应关系中的知识表达动态。C1 的错误轨迹仍需有足够的可判定错误事件和可比较覆盖。C2 的真实支持计数和 C3 的机制干预另行设计。若主要检验失败，报告实际原因并转向公开替代轨迹；如果主要指标因参考获取或执行故障无法计算，标记未完成，区分于科学失败。所有标签注明机器取证或历史标签来源，人工审核单独记录。
