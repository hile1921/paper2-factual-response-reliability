# 已完成跨模型数据的阶段分析口径

分析角色：探索性、描述性阶段分析。核心贡献与原实验协议不变；不新增 GPU 生成，不补选样本以获得显著性。固定快照包含 32 个完整检查点。Pythia 原定 10k/70k/143k 三阶段尚未齐备，绝不以 0/2k 替代正式阶段。

在汇总结果前，经数据结构检查发现：400 条 C3 记录仅有 200 个不同的“上下文+问题+有序候选”组合。十个国家已各自出现在真实主体条件；配对国家的置换条件再产生相同问题。因此保留全部原始记录，主要分析使用 swapped=false 的 200 条唯一问题；swapped=true 用于重复一致性核查，不能作为独立样本扩充。此发现来自结构检查，不依赖正确率。

统计单位：国家10个，主体对5个。按模板平均、固定解码种子平均后计算国家配对差，5000次聚类bootstrap、seed20261129；国家CI与五主体对CI并列，少数主体只解释为探索。greedy与sample101–104分开，不把四个解码种子当四个独立训练重复。

C3指标：正确候选相对竞争候选的总log-likelihood差、平均token log-likelihood差、二选一正确率、仅限两候选归一化概率；后者不是开放生成概率，平均token指标对应的归一化值不解释为序列概率。开放生成按既有首答案规则划分正确、指定竞争答案、无答案、无法核验；指定竞争答案频率是错误下界之一，不能把其他输出当正确。补充冻结外部事实参考核验，单列无法核验与所有非正确输出的宽敏感性上界。首答案正确不代表完整输出无错误。

主体绑定：在同一国家对、同一关系/模板/上下文下，对两个主体的固定答案A相对B的分差作交叉差；表示为两国各自 correct-minus-competitor margin 的平均。固定选择同一个答案时该指标为0，不能用真实/置换条件准确率均值差代替它。正确双向选择率和仅发生答案翻转率分别报告。

预先列定上下文对比：CorrectOnly-NoContext、OtherOnly-NoContext、Both-NoContext、Neutral-NoContext、CorrectOnly-OtherOnly。时间对比：每模型所有已完成相邻阶段及最早到最晚；初始化起点单列探索。模板、关系、总/平均token评分和解码方式全部分开。跨条件p值仅对五个独立主体对的符号翻转精确检验，并在每模型/阶段/关系/指标内对五个上下文对比做Holm处理；不以bootstrap CI当作多重检验校正。

评分—生成脱节：NoContext下候选正确且开放生成未被确认正确的比例；候选错误且生成确认正确的比例。前者不直接称作事实幻觉。比较候选选择增长与正确生成增长的差异，并保留未知输出。不把关联称因果。

C1：只读取本快照已完成检查点，对两原面板、关系、解码方式分别使用已有机器证据规则。作为C3共同事实匹配和生成侧对照，不改变C1主结果或新增生成。分类输出包括correct_verified、wrong_confirmed、type_mismatch、nonanswer、unverified。

C2：统一QID/P36/答案QID Fact ID，保留旧训练证据中直接支持、共现、矛盾及实际错答的其他关系。原模型训练证据只用于原模型；不能转移为Pythia/OLMo/AMBER的训练曝光。OLMo Dolma-v1.5局部读取证据另列，没有有序训练曝光则不计算跨模型H5/H7因果或增量解释结论。C3人为配对的竞争候选与C1实际错误答案是否相同逐条检查，禁止强行连接。

所有失败、不确定输出、缺失阶段、实体/关系不匹配和证据不足均交付。报告将区分已观测、探索性、未知；不证明内部机制。
