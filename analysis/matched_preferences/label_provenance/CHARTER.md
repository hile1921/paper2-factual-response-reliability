# C1 分类章程 v1.0

本章程采用用户于 2026-11-11 指定的六类错误和九种输出状态。分类框架在本轮统计前固定，应用于现存原始输出。旧测量结果保留，今后修改另升版本。

## 错误类型

F1 Entity Error，主体或答案实体错误。F2 Relation Error，关系错配，须有关系证据。F3 Attribute / Value Error，属性或数值错误。F4 Temporal Error，时间混淆，须有明确目标时间和时效证据。F5 Scope Error，地理、行政或定义范围错误，须证明实际断言的范围错误。F6 Fabricated Fact，编造的实体、事件、关系或属性，须有充分的不存在或伪造证据。

错误可以多标签。主要类型按证据能够证明的最具体错误选取，次要类型需各自证据。当前首都错城只直接证明 F1。错城本身不自动证明 F2、F4 或 F5，检索不到实体不自动证明 F6。证据不足时保留待定类型。一个回答的错误标志只计一次。

## 输出状态及命题

输出状态使用 Correct、Incorrect、Mixed、Refusal、No Answer、Non-responsive、Incomplete、Unverifiable、Contradictory。Refusal 指明确拒绝提供答案，No Answer 指明确不知道或无法确定，Non-responsive 指未回答目标问题。Incomplete 保存已表达命题的独立真值。Unverifiable 保留测量不确定性。Mixed 要有已核验正确命题和已核验错误命题。Contradictory 要有同主体、同关系及兼容时间范围的相冲突断言。单纯出现“however”或“or”不能直接判矛盾，两个相同城市的同义重述也不能判矛盾。

任何已证明的明确错误命题均令该回答 FEI 事件为 1，包括 Mixed、Contradictory 和已表达错误事实的 Incomplete。后文出现正确答案不抵销前文已表达的错误。否定、假设、引用及显式撤回须核对其断言效力。全文包含尚未核验的其他命题时，已证明错误仍保留，另记全文覆盖不足。

## 分母及不确定性

全部有效生成记录为 FEI 和 AFR 的分母。当前每个问题有两模板、五解码，重复生成按回答计数，主体聚类推断保留这些重复。另报告独立事实数。

FEI = 含至少一个已证明错误的回答数／全部有效生成数。CFER = 同一错误回答数／提供实质性事实回答数。实质性事实回答包含正确、错误、Mixed、Contradictory，以及已经作出目标事实断言但真值未定的回答。该分母区别于旧版“已核验正确＋错误”。AFR 以确定的任务失败为下界，以加上任务成功未定者为上界。拒答和无答案计入 AFR，不计入 FEI。

FEI 的识别上界只对仍可能包含错误的未核验回答追加计数，条件于已接受的输出状态和已检查命题范围。CFER 同时报告未知真值及实质性分母待定的联合极端界。识别界与主体 bootstrap 的 95% CI 分开列示。类型计数的主要类型总和必须等于已确认错误回答数。

## 当前任务适用性

现有 C1 只包含 Capital 和 Country 两个关系，均为实体补全，缺少数值目标。部分主体有多个参考答案或时间限定，Country 的“is a part of／is located in”也容许多层级真命题。F3 的确证机会有限，F4 需要原提示时间范围支持，F5 需要额外范围证据，F6 需要正面排除实体存在的证据。分类框架全部保留，当前已确认覆盖与未覆盖情况分别输出。
